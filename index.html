SCROLL SNAP

Syntax

 
            /* for the scroll container */ 
            scroll-snap-type: y proximity;
            scroll-snap-type: x mandatory;
x which axis you want to scroll to snap along. proximity will snap to if it's near to snap point mentioned in the scroll-snap-align in scroll items mandatory is always snap to the closest snap point. Mandatory will some time gets in the way

Syntax

 
            /* for the scroll container */ 
            scroll-snap-type: y mandatory;
            scroll-snap-type: x mandatory;

            /* for the scroll items */ 
            scroll-snap-align: start;
            scroll-snap-align: center;
            scroll-snap-align: end;
scroll-snap-align sets how the element should be snapped. Will make sense, with the example.

One line to trigger View Transition

One line to trigger View Transition

            
              document.startViewTransition(...)
At it's core regardless of which framework you use, same document view transition revolves around single line of code

            :root {
              view-transition-name: root;
            }

            .root {
              view-transition-name: root;
            }
When invoked, browsers automatically captures snapshot of all element that have view transition name property declared on them.
Then the provided callback is executed, that updated the DOM, browser takes snapshot of new state
These snapshop are arranged in tree of pseudo elements. Which are animated using power of CSS Animations. Snapshop pair of old and new state smoothly transitioned from their old size and position to new location while their content cross fades
