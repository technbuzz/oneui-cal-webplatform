UI Challenge with Web Platform

Purpose of this session is to know how capable a web platform is.

Web Experience

  • Fundamentally a call & response between you & your users
  • Invest in Quality Web Experiences & Interactions
  • Easy to built with Native Web Platform
  • No Third Party Scripting for Optimal Performance
A web experince is fundamentally a call and response between you and your users. And that's why it's so imortant to invest in quality web experiences and user interactions. It shouldn't be so hard to build these, robust engaging interactions with the native web platform. no added third party scripting to manage or to slow down optimal performance.
We will take an example from another platform and replicate it via The Web. I have screen recorded how interacting with calendar looks on Samsung.
